# Playlet, forked

This folder is a fork of [Playlet](https://github.com/iBicha/playlet), an unofficial YouTube client for Roku by Brahim Hadriche, licensed under the GNU Affero General Public License v3 (see `LICENSE`).

- Taken from upstream commit `5b204f209534a95e2283ff36c63b6c166d02ec68` (version 0.48.10).
- Left out to keep the repository small: `docs/`, `playground/`, `integration-tests/`.
- Everything changed since is in this repository's history: `git log -- playlet/`.

To pull in a newer upstream, diff the upstream tree against that commit and apply the result here.
